# 커피 주문 앱

## 1. 프로젝트 개요

## 1.1 프로젝트 명
커피 주문 앱

## 1.2 프로젝트 목적
사용자가 커피 메뉴를 주문하고, 관리자가 주문을 관리할 수 있는 간단한 풀스택 웹 앱

## 1.3 개발 범위
- 주문하기 화면(메뉴 선택 및 장바구니 기능)
- 관리자 화면(재고 관리 및 주문 상태 관리)
- 데이터를 생성/조회/수정/삭제할 수 있는 기능

## 2. 기술 스택
- 프런트엔드 : HTML, CSS, 리액트, 자바스크립트
- 백엔드 : Node.js, Express
- 데이터베이스 : PostgreSQL

## 3. 기본 사항
- 프런트엔드와 백엔드를 따로 개발
- 기본적인 앱 기술만 사용
- 학습 목적이므로 사용자 인증이나 결제 기능은 제외
- 메뉴는 커피 메뉴만 있음

## 4. 백엔드 개발 PRD

### 4.1 데이터 모델

#### Menus (메뉴)
| 필드 | 설명 |
|------|------|
| 커피 이름 | 메뉴명 (예: 아메리카노(HOT)) |
| 설명 | 메뉴 간단 설명 |
| 가격 | 기본 가격 (원) |
| 이미지 | 메뉴 이미지 URL 또는 경로 |
| 재고 수량 | 현재 재고 개수 (관리자 화면에서 조회·수정) |

#### Options (옵션)
| 필드 | 설명 |
|------|------|
| 옵션 이름 | 옵션 표시명 (예: 샷 추가, 시럽 추가) |
| 옵션 가격 | 추가 금액 (원) |
| 연결할 메뉴 | 해당 옵션을 제공하는 메뉴와의 연결 (Menus 참조) |

#### Orders (주문)
| 필드 | 설명 |
|------|------|
| 주문 일시 | 주문 접수 시각 |
| 주문 내용 | 메뉴, 수량, 옵션, 금액 (또는 주문 상세 목록) |
| 주문 상태 | 주문 접수 → 제조 중 → 완료 |

---

### 4.2 데이터 스키마를 위한 사용자 흐름

① **메뉴 표시**  
Menus에 있는 내용을 가져와 브라우저 화면에 표시한다. Menus 정보 중 **재고 수량**은 관리자 화면에만 표시한다.

② **장바구니**  
사용자가 앱 화면에서 커피 메뉴를 선택해 담고, 선택 정보는 장바구니에 표시된다.

③ **주문 저장**  
장바구니에서 **주문하기** 버튼을 클릭하면 주문 정보를 **Orders**에 저장한다. Orders에는 **주문 시간**과 **주문 내용(메뉴, 수량, 옵션, 금액)**을 담는다.

④ **주문 현황 및 상태 변경**  
Orders에 있는 정보를 관리자 화면의 **주문 현황**에 표시한다. 주문의 기본 상태는 **주문 접수**이며, 관리자가 **주문 접수** 버튼을 클릭하면 **제조 중** → **완료**로 상태가 변경된다. (주문 접수 상태일 때 '주문 접수' 클릭 → 제조 중, 제조 중일 때 '제조 완료' 클릭 → 완료)

### 4.3 API 설계

| 목적 | API 동작 |
|------|----------|
| **주문하기 메뉴 진입** | 주문하기 화면을 열면 데이터베이스에서 **커피 메뉴 목록**을 조회하여 화면에 표시한다. (메뉴 목록 API) |
| **주문 제출** | 사용자가 커피를 선택하고 **주문하기** 버튼을 누르면, **주문 정보**를 데이터베이스(Orders)에 저장한다. (주문 생성 API) |
| **재고 반영** | 주문 정보에 따라 **메뉴 목록(Menus)의 재고 수량**을 차감(또는 갱신)한다. (주문 처리 시 재고 수정) |
| **주문 조회** | **주문 ID**를 전달하면 해당 **주문 정보**를 반환한다. (주문 단건 조회 API) |

#### API 요약 (추가 구현 시 참고)
- **GET** 메뉴 목록: 커피 메뉴 + 옵션 정보 조회 (재고는 관리자용 API 또는 별도 필드로 제어)
- **POST** 주문 생성: 주문 내용(메뉴, 수량, 옵션, 금액) 저장 및 재고 차감
- **GET** 주문 조회: 주문 ID로 주문 상세 조회
- **GET** 주문 목록: 관리자 주문 현황용 (필요 시 상태별 필터)
- **PATCH/PUT** 주문 상태 변경: 주문 접수 → 제조 중 → 완료
- **GET** 재고 조회 / **PATCH** 재고 수정: 관리자 재고 현황용
