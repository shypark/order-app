# COZY - 커피 주문 앱 (프런트엔드)

React + Vite + JavaScript 기반 프런트엔드입니다.

## 개발 환경

- **React** (바닐라 JavaScript, JSX)
- **Vite** 7.x
- Node.js 18+

## 실행 방법

```bash
# 의존성 설치 (최초 1회)
npm install

# 개발 서버 실행 (기본: http://localhost:5173)
npm run dev

# 프로덕션 빌드
npm run build

# 빌드 결과물 미리보기
npm run preview
```

## 폴더 구조

```
ui/
├── public/          # 정적 파일
├── src/
│   ├── assets/      # 이미지 등 리소스
│   ├── App.jsx      # 루트 컴포넌트
│   ├── main.jsx     # 엔트리
│   └── index.css    # 전역 스타일
├── index.html
├── package.json
└── vite.config.js
```
